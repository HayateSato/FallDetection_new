What does each status mean?

healthy — service responded to its probe within 3 seconds.

degraded — service is partially configured (e.g. file-based MLflow instead of a tracking server). Not an outage, but worth noting.

down — service did not respond, or responded with an error code. The "details" line tells you why.

The overall banner is healthy only when every service is healthy. If any one service is down, the banner turns red. If only degraded states are present, the banner is amber.

What this dashboard does NOT show

  • Latency, throughput, request rates → Grafana ml_server_overview
  • Model confidence drift → Grafana model_performance
  • Logs → kubectl logs in production, or local terminal output
  • Pod CPU/memory → kubectl top pods or Grafana

This is intentional. The job here is "is anything obviously broken right now?" For investigation you go to the right tool — not this page.
